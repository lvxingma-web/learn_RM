##近日都做了些什么

针对于学长给的考核目标，我大概将我的学习路线分为了这几个方向：
1.C++的STL的收尾 
  我在确定我准备参加RM的考核前，我的代码基础仅仅包含：1.系统学习C语言和数据结构初阶 2.系统学习C++到类和对象。当我大概了解到考核的内容时，让trae给我简单的列举出学习的路线，我便确定了先将目标放在C++部分的收尾，主要包括继承、多态、模板和STL。相较于我以前系统学习语言的时候，进度快了
  不是一点半点，仅用了三天的时间学完了系统学习的一百多个小时，对于这些知识的掌握也仅仅只达到了知道与会用，为了面对考核不得不做出此举，但是对于系统性学习语言，考核之后必须回头来重新过一遍，我已经能感受到`基础不牢，地动山摇`的感觉了。

2.linux基础学习（Ubuntu）
linux的学习本来在我没准备入队之前，是在C++部分之后的，所以对于从来没接触过linux的我来说，刚开始手足无措，但好在经过一些文章的阅读，大概知道了一些linux常用的语法（很基础）

3.git和github的简单使用 
阅读完一篇git与github的使用教程，对于在Ubuntu下使用git也算是浅浅的了解了，但是目前还没有一些实践的过程，现在这份push算是我第一次提交一个属于自己学习过程的仓库

4.自瞄方向的必答题
由于开始学习这些，实在是一头雾水没有任何方向，不得不求助于AI的帮助，我首先让他们给予我简单学习路线的列举、所需要的知识。我在逐个攻破学习，第一个接触的知识是CMake，由于以前系统学习C语言的时候已经对预处理编译链接有了一定的了解，所以这一部分对我来说不算太难理解;第二个知识点就是针对必答题所需要的OpenCV方面的知识了，读图片->读视频->分通道->通道相减->二值化->形态学处理->用旋转矩形框定->筛选灯条->灯条匹配->组成装甲板->划线及写文字。必答题是针对传统的装甲板识别，学习到了传统方案的一些所需要的函数及用法（浅学）。


5.自瞄方向加试题
加试题就是运用YOLO、分类器、PnP、IMU来识别装甲板位四点、位置，YOLO是队内已经训练好的模型，我们可以用YOLO代替传统方案中找到装甲板四点的过程，将每一帧转化成模型所需要的尺寸，模型会返回每帧中装甲板的四点，我们在通过图中四点、实际装甲板的大小和相机参数通过PnP算出对于相机坐标系的xyz以及装甲板的偏转、距离，然后在通过机体参数去算出装甲板针对机体坐标系的位置，IMU的作用是描述机体的旋转姿态，我们可以通过IMU将机体坐标转化为世界坐标。
