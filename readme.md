## 近日都做了些什么

针对学长给出的考核目标，我将学习路线分成了以下几个方向。

### 1. 补充 C++ 知识

准备参加 RM 考核之前，我系统学习过 C 语言和初阶数据结构，C++ 则学到了类与对象。

了解考核内容后，我让 Trae 帮我梳理了学习路线，并决定先补充继承、多态、模板和 STL 等知识。相比之前系统学习语言的节奏，这次进度快了很多：我用三天时间快速学习了原本一百多个小时课程覆盖的内容。

不过，目前对这些知识的掌握主要停留在知道概念和初步使用的程度。为了准备考核，我暂时选择了这种学习方式；考核结束后，还需要重新系统学习，并通过练习巩固。我已经感受到了“基础不牢，地动山摇”。

### 2. Linux 基础学习（Ubuntu）

在原来的计划中，Linux 是完成 C++ 学习之后的内容。由于此前没有接触过 Linux，刚开始使用 Ubuntu 时有些手足无措。

通过阅读文章，我初步了解了一些常用命令，但目前仍处于入门阶段。

### 3. Git 与 GitHub 的简单使用

阅读使用教程后，我初步了解了如何在 Ubuntu 下使用 Git，但实践经验还比较少。这次提交并推送学习记录，是我第一次将自己的学习过程整理到仓库中。

### 4. 自瞄方向的必答题

刚开始接触自瞄时，我对所需知识和学习方向都不清楚，因此借助 AI 梳理了学习路线，再逐项学习。

首先学习的是 CMake。此前学习 C 语言时，我已经了解过预处理、编译和链接，因此理解构建流程相对容易一些。

接着学习了必答题涉及的 OpenCV 知识。传统装甲板识别流程可以概括为：

1. 读取图片或视频帧。
2. 分离颜色通道，并进行通道相减。
3. 二值化与形态学处理。
4. 利用旋转矩形描述候选区域，筛选灯条。
5. 匹配灯条，组成装甲板。
6. 绘制识别结果，并添加文字说明。

通过必答题，我初步接触了传统装甲板识别方案中的一些 OpenCV 函数及其用法，还需要进一步理解各步骤的作用和参数选择。

### 5. 自瞄方向的加试题

加试题涉及 YOLO、分类器、PnP 和 IMU。以下是我目前对整体流程的理解，后续还需要结合代码逐步核对。

- **YOLO**：使用队内训练好的模型检测装甲板，获取后续处理需要的图像关键点。输入图像需要按照模型要求进行预处理。
- **分类器**：用于装甲板的进一步分类，具体输入、输出和标签含义还需要结合代码确认。
- **PnP**：结合图像中的四点、装甲板的实际尺寸和相机参数，估计装甲板在相机坐标系中的位置与姿态，并据此计算距离。
- **坐标变换**：根据相机与机体之间的旋转和平移关系，将相机坐标系中的位置转换到机体坐标系。
- **IMU**：提供姿态信息。在坐标系定义和时间对齐正确的前提下，可用于坐标系之间的旋转变换。若要得到完整的世界位置，还需要机体在世界坐标系中的平移信息。

## 这篇 README 的目的

仓库中的加试题代码由 AI 辅助编写。我的目标是在 AI 的辅助下读懂代码，并逐步形成独立实现的能力。

目前采用的学习方法是：

1. 理解每一部分的原理和作用。
2. 对照代码，梳理输入、处理过程和输出。
3. 自己尝试复现，再通过运行结果检查理解是否正确。

这是我目前为准备考核选择的学习方式。借助 AI，我初步了解了一个自瞄项目涉及哪些知识，但理解和掌握这些内容，仍然需要自己动手练习。

这份 README 也用于记录学习过程，方便以后回顾。漫漫长路，我会一步一步走。

## 不足与自省

这段时间的学习离不开 AI 的帮助。在准备考核的过程中，我还没能从头系统学习所有相关知识，对一些内容的理解比较浅，这与我希望扎实学习的初心还有差距。

计算机视觉（CV）的学习是一条漫长的道路。入队考核是近期的小目标，之后我希望重新梳理基础知识，并系统学习计算机视觉。

入队不是我的最终目标。我更希望自己能切实进步，逐渐做到独立发现问题、分析问题和解决问题。AI 可以辅助学习，但要把知识内化，仍然需要自己的探索、练习和试错。
