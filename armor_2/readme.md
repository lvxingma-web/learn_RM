# 项目介绍

以个人对该项目的分析和理解写出

## 1.该项目能实现的功能

项目实现逻辑：读视频->读每一帧->YOLO模型找出四点->独立分类器判断装甲板类型->PnP解算装甲板的距离->画框标点->写装甲板信息

该项目的实现是在AI的辅助下实现，本人掌握程度：读懂代码逻辑以及各个部分函数的作用（函数的返回值以及功效）、了解了部分函数内部的实现逻辑，如：PnP解算出旋转向量以及平移向量，为何要转换成旋转矩阵的形式去计算深度判断PnP给出的候选目标是否合适。

项目中有几个可能不足的点：1.这里的装甲板类别是由YOLO返回的22个数中下标为13～21号中分数最高的判断，由于没办法判断独立分类器返回的最高分数的下标所对应的类别，这里只将独立分类器返回的下标标注在图上。2.也没有将相机坐标转换成机体坐标。3.也没有用到IMU，大概能理解IMU的作用：用来算机体的姿态的，以及转换到世界坐标，不知道这个理解有没有错误，没用使用的原因是因为据AI分析没办法判断视频与资料给出的IMU的时间辍是否对应，前期让AI生成的文件中包含IMU的部分，但写入csv中的IMU都是空，因为没办法判断时间辍与视频是否对应，后面我干脆删去了这部分。4.项目中没有写入csv的部分，因为本人对于文件读写操作还不是特别了解，上一份让AI编写的一份代码中有包含这一部分，因为那段代码我读了五六天还是只读了个框架，所以给自己降低了一点标准。
